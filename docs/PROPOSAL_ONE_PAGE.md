## 项目名称

MoonTrace：MoonBit Agent 执行轨迹观测与调试工具

## 项目目标与应用场景

MoonTrace 面向使用 MoonBit 开发 AI Agent 和工具调用工作流的开发者，解决 Agent “只能看到最终答案、难以定位中间步骤问题”的调试痛点。一次 Agent 请求通常会经过规划、检索、计算、知识库访问和回答生成等步骤；当结果错误或某个工具失败时，开发者需要知道失败位置、调用层级、输入输出和耗时。

本项目提供 MoonBit 原生的轻量追踪能力，让开发者可以用 `@trace.span` 包裹 Agent 步骤，自动得到可检查的嵌套 trace 树。项目不依赖云端服务或 API key，适合本地开发、测试和教学演示。

## 核心交付物与功能范围

本期交付一个可运行的本地 MVP，范围包括：

- Trace 和 Span 数据模型，记录输入、输出、状态、错误、事件、元数据和耗时；
- 嵌套工具调用的父子关系，以及显式上下文传播 API；
- 内存存储和 JSON 文件存储，支持保存、读取、删除和摘要过滤；
- CLI 的 `list`、`show`、`export`、`export-all` 和 `delete` 命令；
- ANSI 终端树形查看器和自包含 HTML 时间线导出器；
- 研究型 Agent 示例，演示 Web 搜索、计算器、知识库超时和降级回答。

本期不包含真实 LLM 接入、远程观测服务、数据库部署和多用户权限系统，避免超出可验收范围。

## 技术路线与可行性

项目完全使用 MoonBit 实现，按 `trace`、`storage`、`tui`、`exporter` 和 `cli` 划分模块。核心 tracer 在 span 创建时记录当前父节点，在闭包成功或失败时更新 span；墙上时钟用于持久化执行时间，单调时钟用于计算耗时。JSON 文件与索引文件使项目无需数据库即可完成本地持久化，HTML 导出采用内联 CSS/JS，可直接打开。

当前代码已经完成构建、测试和端到端验证：`moon build` 通过，15 个单元测试全部通过；示例可以生成成功和错误 trace，CLI 可以列出、查看并导出 HTML。模拟工具保证评审无需 API key 即可复现关键路径。

## 风险与应对

- MoonBit 工具链版本变化可能带来 API 或编译差异：README 固定依赖和验证命令，并保留测试作为回归入口。
- 全局 tracer 不适合未经处理的并发隔离：当前 MVP 提供显式上下文传播，后续再扩展更完整的并发模型。
- 输入输出可能包含敏感信息：当前版本定位为本地调试工具，后续增加脱敏和采样策略。
- JSON 文件不适合大规模生产写入：MVP 保持本地轻量边界，后续可增加数据库或远程存储后端。
